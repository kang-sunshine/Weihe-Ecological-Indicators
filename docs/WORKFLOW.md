# Workflow
1. Set the basin asset in export_climate_calendar.js if preparing climate inputs in Earth Engine. The script uses PML timestamps and ERA5-Land climate data. Supply the previously exported L2 ecological layers separately. Inventory annual stacks before aligning the ecological cube and constructing the L3 climate NetCDF.
2. Run L4.1 for Sync and uWUE, L4.2 for pixel-by-phase baseline anomalies, and L4.3 for negative components and RMS damage. L5.0 climate masks may be built separately.
3. Run L5.1 response extraction, L5.2 lifecycle reconstruction and L5.3 historical event metrics. Preserve historical observed legacy and its original stopping rule. Run catalogue overlap and HEAT-only comparisons on matched grid cells.
4. In m5 use prepare_m5, extract_m5 and analyse_m5 with survival_m5. Supply the referenced pre-existing event caches. Recovery follow-up starts at termination and requires two valid post-peak phases. A subsequent event right-censors KM follow-up and competes with recovery in AJ. Report direct Extreme-minus-High spatial contrasts.
5. L5.4A fits severity candidates. L5.5B5 and L5.5C calculate and classify local responses. The archive retains historical names. Interpret the positions as candidate references and distinguish eligible from supported units.
6. L6 residual construction precedes the empirical greening analysis, modelled P20-minus-P80 contrasts and ALE. Use the archived model parameters. Buffered CV and fold-specific recalibration use their own m4_prepare inputs.
7. Use the robustness branches separately on common cohorts. M6 compares LOYO and early references, M8 stratifies by land cover and compares terrain predictors, and the components and response_bias branches support the supplementary diagnostics. The HCL analysis consumes frozen model predictions.
8. Supply each figure project with its expected source tables and geography. The plot scripts use relative project layouts. A prepared input at a downstream stage can replace earlier stages. The per-script paths and archived code locations are in config/layout.json.
